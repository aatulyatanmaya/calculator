# Changelog

## 1.0.0 — Scientific Edition

- Replaced the basic calculator screen with a responsive modern interface.
- Added persistent light/dark theme selection.
- Added keyboard input and accessible live result announcements.
- Added calculation history with result reuse and clear-all action.
- Added square root, square, exponent, trigonometric and logarithmic operations.
- Added calculator memory controls.
- Added visible validation errors and division-by-zero protection.
- Added decimal-safe basic arithmetic and large/small number formatting.
- Added calculation engine and UI tests, README, and developer documentation.
